# Cuentitas

Finanzas personales para Windows 11, hechas para Argentina.

Registrá cada gasto e ingreso, tus cuentas en pesos y en dólares, tus compras de dólares (oficial, MEP, blue…),
tus servicios con vencimientos, tus metas de ahorro y tus presupuestos, y descubrí cuánto se va en gastos prescindibles.

- **Privada:** todo queda en tu computadora, en tu usuario de Windows. Sólo se consulta en internet la cotización
  pública del dólar (se puede apagar).
- **Rápida:** Ctrl+N, monto, categoría, Enter.
- **Para la familia:** cada persona usa su propio usuario de Windows y tiene sus propias cuentas.

## Instalar
1. Ejecutar `Cuentitas-Setup-1.0.0.exe` (no pide permisos de administrador).
2. La primera vez, la bienvenida te guía para cargar tus cuentas, tu sueldo y tus servicios.

Para **actualizar**, ejecutá el instalador de la versión nueva: tus datos se conservan.
Versión portable (sin instalar): descomprimir `Cuentitas-win-x64.zip` y abrir `Cuentitas.exe`.

## Qué tiene
Inicio · Movimientos (con cuotas) · Vencimientos (con avisos de Windows) · Metas (con inflación y simulador de
recortes) · Presupuestos · Reportes · Cuentas (pesos y dólares) · Categorías · Exportar a Excel ·
Copias de seguridad · PIN / Windows Hello · Tema claro y oscuro.
